# 🚀 ProdPulse – Production Management System

![React Native](https://img.shields.io/badge/React%20Native-Expo-blue)
![Firebase](https://img.shields.io/badge/Firebase-Authentication-orange)
![TypeScript](https://img.shields.io/badge/TypeScript-5.x-blue)
![License](https://img.shields.io/badge/License-MIT-green)

ProdPulse is a modern production management application developed for **Technico Industries Ltd.** to digitize production operations, replace manual paper-based records, and provide real-time visibility into manufacturing performance.

The application centralizes production data from multiple departments, enabling supervisors and management to monitor KPIs, manage production lines, generate reports, and improve operational efficiency.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/technico-management.git
```

Move into the project

```bash
cd technico-management
```

Install dependencies

```bash
npm install
```

Start Expo

```bash
npx expo start
```

---

# 🔐 Environment Variables

Create a `.env` file.

```env
EXPO_PUBLIC_FIREBASE_API_KEY=
EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=
EXPO_PUBLIC_FIREBASE_PROJECT_ID=
EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=
EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
EXPO_PUBLIC_FIREBASE_APP_ID=
```

> **Note:** Do not commit your `.env` file to GitHub.

- Paperless production tracking
- Real-time production visibility
